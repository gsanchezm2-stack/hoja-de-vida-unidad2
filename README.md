# Hoja de Vida — Gabriel Alfonso Sánchez Martínez

Sitio web de hoja de vida personal, desarrollado como Actividad de la Unidad 1 de
Fundamentos de Desarrollo de Software Web (CTEV, Universidad de Cartagena).

## Qué incluye

- 5 páginas HTML con navegación entre ellas: Perfil, Formación, Experiencia,
  Proyectos y Contacto
- Una hoja de estilos CSS única (`css/estilos.css`)
- Imágenes propias (foto de perfil e ilustraciones de proyectos)
- Barra de navegación vertical fija, con íconos por sección
- Formulario de contacto

## Estructura del proyecto

```
hoja-de-vida/
├── index.html          → Perfil
├── formacion.html       → Formación académica
├── experiencia.html     → Experiencia laboral y habilidades
├── proyectos.html       → Proyectos de software
├── contacto.html        → Datos de contacto y formulario
├── css/
│   └── estilos.css
└── img/
    ├── foto.jpg
    ├── ciudadalerta.svg
    ├── smartstock.svg
    └── nexastore.svg
```

## Tecnologías

HTML5, CSS3 (sin frameworks ni JavaScript). Tipografías Archivo y Newsreader vía
Google Fonts.
