Sobre mí

Empecé arreglando computadores y terminé queriendo entender también el software que corre dentro de ellos. Hoy hago mantenimiento de equipos en el sector retail, y al mismo tiempo desarrollo aplicaciones web completas: base de datos, API y la interfaz que ve el usuario.

Me interesa el software que resuelve problemas concretos de la gente: control de inventario para un negocio pequeño, un canal para que un barrio reporte lo que pasa en su calle. La tecnología me gusta cuando sirve para que una comunidad se organice mejor.

Lo que hago

  • Mantenimiento preventivo y correctivo de equipos de cómputo, periféricos y redes.
  • Desarrollo de APIs REST con Node.js y Express, y con Java y Spring Boot.
  • Interfaces web con React y aplicaciones móviles con React Native.
  • Bases de datos MongoDB y PostgreSQL.
  • Control de versiones con Git y despliegue en Railway y Vercel.

Hacia dónde voy

Busco una práctica o un primer puesto como desarrollador junior donde pueda aportar lo que ya construí por mi cuenta y seguir aprendiendo con un equipo. Mientras tanto, cada proyecto que hago lo llevo hasta el final: probado, documentado y publicado.
